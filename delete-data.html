Delete your local data

Roamwise has no publisher-operated user account or travel-data server in this build.

  1. In Roamwise, open Traveler settings.
  2. Export a backup if you want to keep a copy.
  3. Select Clear this workspace, review the confirmation, then select Clear workspace.

The release candidate clears local travel, approvals, profile, checklists, imported tickets and GPS observations, stops tracking, cancels Roamwise reminders and disconnects native inbox credentials. Original provider messages and exported backups remain where you saved them.

Revoke Google or Microsoft access separately in the provider account if desired. Computer inbox-service files are separate from browser data. Contact support at contact@tegadv.com for help; never email passwords or codes.
